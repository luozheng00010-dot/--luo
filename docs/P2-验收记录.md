## P2-08 上传货号/品类与逐行校验 ✅（后端 + API）

- `POST /api/assets/import`：逐项校验货号（strip 后 1~64 字符、不转数字、保留前导零）与
  品类状态；无效行进入 `invalid_items` 逐行报告并定位 `import_item_id`，不影响有效行（T26）。
- 幂等键 = 清单内容哈希：同清单重复提交返回同一 job_id 不重复建任务（6.1）。
- 每个导入项以稳定 ID 绑定属性，与文件名无关（T28 的服务端基础）。
- `GET /api/assets?sku=` 精确筛选：`00123` 命中且不匹配 `00124`（T27）。

## P2-01/02 导入管线、媒体探测与去重 ✅（后端）

- `app/services/ingest/probe.py`：FFprobe 探测时长/尺寸/帧率/旋转/音轨；SHA-256 流式哈希；
  托管复制前检查磁盘空间。
- 任务处理器 `import_assets`（独立 Worker 进程）：逐项校验 → 探测 → 去重 → 入库。
  单文件失败不中断批任务（T04 部分）：零字节 → `zero_byte_file`、无法解码 → `probe_failed`。
- 同内容不同文件名 → 单素材实体 + 两条来源记录（T01）；重复文件属性不一致 → `conflict`
  待处理，`resolve-conflict` 显式选择沿用或修改原属性并写 `asset_metadata_changes` 审计（T32）。
- 超过 5 秒标记 `over_duration=True`，保留完整时长，不静默截断（4.1.5）。
