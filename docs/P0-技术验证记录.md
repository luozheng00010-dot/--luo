# P0 关键技术验证记录

- 日期：2026-09-13
- 机器：Apple Silicon macOS（darwin 25.5.0 arm64），本机实测
- 结论：**媒体工具链与本地嵌入模型验证通过**；供应商对比、样本集与预算确认依赖用户提供素材与账号，列于待确认清单。

## 已验证项

### P0-06 媒体工具及目标机器 ✅

- FFmpeg 9.0.1（homebrew `ffmpeg-full`，keg-only，路径 `/opt/homebrew/opt/ffmpeg-full/bin/ffmpeg`）。
  - 原 `ffmpeg` 6.0_1 构建损坏（libvmaf dylib 失联），已 `brew reinstall ffmpeg` 升级至 9.0.1；
    但标准 formula **不含 libass**，必须使用 `ffmpeg-full`（含 libass、drawtext、loudnorm、libx264、aac）。
- 字体：内置 OFL 许可的 [Noto Sans SC](backend/app/assets/fonts/NotoSansSC-Regular.otf)
  （`app/assets/fonts/`，含 LICENSE-OFL.txt）。实测系统 PingFang 经 libass/fontconfig 无法直接命中，
  内置字体是计划 P5-04 的既定要求，且可复现。
- 自动化验收：`scripts/p0_media_check.sh`
  1. 能力检查：libx264、aac、subtitles/ass（libass）、loudnorm 全部存在；
  2. 10 段 3 秒短素材（模拟 <5s 规格）拼接为 30 秒 1080×1920@30fps；
  3. 中文 ASS 字幕烧录 + 配音/背景乐混音（loudnorm 目标 -16 LUFS）+ H.264/AAC 导出；
  4. ffprobe 复核：h264 / 1080×1920 / 30fps / 时长 30.00s（容差内）。
- 产物：`data/p0_media_check/sample_30s.mp4`，抽帧目视确认中文渲染无豆腐块。

### 本地嵌入模型（3.2 语义检索选型）✅

- `BAAI/bge-m3` 经 sentence-transformers 在本机加载成功；编码两条中文文本输出 (2, 1024) 向量。
- 模型缓存：`data/models/hf/`。许可：MIT（bge-m3 模型页），可商用，符合 P0 许可验证要求。
